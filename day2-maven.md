#It is a build automation tool and project management tool.
  It is used to create, build , package and manage java applications.
Consists of:
1. Src folder - Contains the main login/main source code of the application
2. pom file - contains the information about the application, the different properties, plugins and dependencies 

Artefact - The main application which is executed and run.

Creating a java project
  To start a java project, visit start.spring.io to initialize the project. It gives you a basic project which you can modify.

Maven Lifecylce
    It has 3:
1. Clean Lifecycle - Deletes any build output generated by previous builds:- mvn clean
2. Default lifecycle
  -validate - Validates the project structure and verifies if all the necessary information is available: mvn validate
  -compile - Compiles the project source code: mvn compile
  -test - Runs the test against the compiled source code: mvn test
  -package - Packages the compiled code into a distributable format e.g. JAR, WAR : mvn package
  -install - Installs the package into a local repository (.m2) for use as a dependency in other projects. :mvn install
  -deploy - Deploys tge package to a remote repository for sharing with other developers and/or environments.

3. Site Lifecycle
    site - Generates project documentation and reports: mvn site
    site-deploy - Deploys the generated documentation to a remote server.
